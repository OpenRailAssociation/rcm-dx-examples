# RCM-DX examples

This repositories contains some example scripts how to interact with RCM-DX
files.

Currently we provide MATLAB and Python scripts which allow loading of a RCM-DX files. 

In MATLAB the loading is performed leveraging a configuration file. The script and a configuration template are
provided in [](Matlab/dataImport_Analysis) Please refer to examples section
within the Matlab folder for more information about how to use this function. 

The Python examples provide basic reading and extraction of data from different RCM-DX files. Please refer to the instuction within the Python folder for more information.  

For more information about the RCM-DX format, please refer to the format
specification available at
<https://github.com/OpenRailAssociation/rcm-dx/blob/main/RCM-DX-Specification_EN.md>
